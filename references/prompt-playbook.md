# 提示词与参考图用法

## 一、四视图参考图的分工（硬规则）

MiniMax H3 换人时参考图通常是角色四视图（一格特写 + 三格全身像），**整张使用，不裁切、不删格、不改动任何一格**。分工写死在提示词里：

- **特写格只负责面部**：面部细节、发型、发饰、五官比例、面部化妆、面部饰品、耳饰
- **三格全身像只负责身体与服装**：身材比例、各种配饰、衣服款式、衣服细节、裁剪长度、胸部大小、腿部长短、腰身长短、脚部鞋靴、露腿程度、露出乳沟程度、背部细节、背部配饰、衣服纹理细节
- 特写格**绝不**提供构图、景别、镜头距离或身材比例；全身像**绝不**改写面部
- 构图、景别、人物占画幅比例、镜头调度与推拉摇移**只由参考视频逐帧决定**
- 原片背景（黑底舞台、灯光、地面、杂志文字）必须原样保留

## 二、长度阈值（最反直觉的一条）

实测结论：**提示词长度会直接压掉换人效果**。

| 提示词长度 | 结果 |
|---|---|
| 15,265 字符（四视图长文 + 大量规则） | 两人**都没换**，模型退化成照着源片重绘 |
| ~240 字符（只有「把 A 换成 P1、B 换成 P2」） | 两人都换，但长袍/长裙细节不稳 |
| **1,091 字符（逐个写出具体服装 + 禁忌）** | 两人都换且全程稳定 |
| ~1,200 字符（四视图分工版） | 稳定，但比具体服装版略松 |

有效区间：**900–1400 字符**。超过 3k 基本会把 `<Video 1>` 的动作条件与参考图条件一起压掉。

## 三、可用模板（1,091 字符版，实测稳定）

```
[视频编辑 + 参考生成] <Video 1> 是参考视频，只决定动作、构图与场景，逐帧照抄：两人走位、姿态、手势、转头、口型、眨眼、神态表情及其节奏，以及机位、镜头、景别、镜头运动、景深、蓝色看台与红台阶、绿色草坪白线、红色跑道、光线、色调和总时长。

画面只有两个人，左边女人、右边男人，两人都必须换人。

左边女人：整张 <Picture 1> 是她的多视图设定图，不裁切不切分不改动。她的脸、发型、发饰、五官比例、化妆、面部饰品、耳饰必须与 <Picture 1> 的特写格完全一致；她的身材比例、配饰、衣服款式与细节、裁剪长度、胸部大小、腿长、腰身长短、鞋靴、露腿程度、露出乳沟程度、背部细节与配饰、衣服纹理必须与 <Picture 1> 的其余全身像格完全一致。她必须穿 <Picture 1> 的砖红与米白配色长裙、V 领内裙、外披米色纱质长衫、高盘发髻与发饰，原浅绿上衣和米色裙子一件都不能留。

右边男人：整张 <Picture 2> 是另一个人的多视图设定图，不裁切不切分不改动。他的脸、发型、发饰、五官比例、化妆、面部饰品、耳饰必须与 <Picture 2> 的特写格完全一致；他的身材比例、配饰、衣服款式与细节、裁剪长度、腿长、腰身长短、鞋靴、背部细节与配饰、衣服纹理必须与 <Picture 2> 的其余全身像格完全一致。他必须换成 <Picture 2> 的墨青灰长袍：交领右衽、宽袖、及踝长袍、内衬浅灰、竹叶暗纹刺绣、深色布靴，长直发束顶；原黑色短上衣、白色 T 恤、黑色长裤一件都不能留，男人的服装必须彻底改变。

特写格只给头脸，不给身材、服装、构图、景别、机位；全身像格只给身体与服装，不改写面部。设定图的多角度是同一个人，不许变成多个人，不许混成新面孔，两人不许串脸串服装。设定图与源视频冲突时一律以设定图为准。

镜头硬规则：构图、景别、两人位置与大小、景深、焦距、虚实、镜头轨迹与 <Video 1> 逐帧完全一致，横构图原样保留，两人全程全身在画面内。禁止推进、推近、变焦、收紧构图，禁止大特写、面部特写、头肩像、半身像，禁止新增机位、重新构图、裁切。结尾最后 2 秒和最后一帧与 <Video 1> 结尾逐帧相同，禁止在结尾推成特写，禁止定格和重复帧。

动作硬规则：两人动作、姿态、手势、转头、眼神、口型、眨眼、表情与节奏逐帧与 <Video 1> 完全一致，不新增、不夸张、不放慢、不加速、不重排。换人不许改变动作、两人间距、构图和景别。不许出现第三个人、镜面人、虚影。

成片完全静音：无对白、无环境声、无音效、无音乐、无音轨。
```

## 四、写提示词的四条经验

1. **必须写出具体服装**。只写「与设定图一致」不够，模型会含糊处理；写上「砖红与米白配色长裙、V 领内裙、外披米色纱质长衫」这种级别，换人才稳。
2. **明确宣布旧服装作废**。每个角色后面跟一句「原 XX、YY 一件都不能留」「必须彻底改变」，能显著减少残留。
3. **两个角色要平行结构**。左边 / 右边分别一大段，句式对称，避免模型把两人混在一起。
4. **动作条件优先于外观**。如果发现动作跟不上，可把「逐帧复制动作」提到最前面并压缩外观段落；但同时要接受外观细节会松一点。

## 五、参考图素材规范

- 尺寸：长边 ≤2556（例：2556×1440 四视图），`refImageSize` 用 `match`（按生成画布面积等比缩放），不要用 `max`（更慢）
- 文件名：改成 ASCII（如 `wlp_ref_female.png` / `wlp_ref_male.png`），中文名在参数链路里容易出问题
- 顺序：`<Picture 1>` = 第一个 ref slot，`<Picture 2>` = 第二个；**顺序与提示词必须严格对应**，错位会串脸
- 首帧构图：参考图人物姿态最好接近源片首帧，姿态差太远会导致生成失败或走形

## 六、动作贴合度不足时的排查顺序

1. 提示词是否过长（先压到 1k 以内）
2. 参考图是否两张都在起作用（单独只用一张测一次，确认 `<Picture 2>` 没被忽略）
3. 步数是否被 turbo LoRA 限制在 4（提高到 6/8 会慢 1.5–2 倍，对快节奏打斗有帮助）
4. 若以上都无效：H3 的 rv2v 条件本身撑不住该素材，考虑换模型（如 SCAIL-2，但它需要 ≥16 GB 显存）
